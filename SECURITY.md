# Security

This repository is an archived, unmaintained reference project. It is not production software, it has not had a professional security audit, and it receives no fixes or support. The book and the [Limitations](README.md#limitations) section of the README list what the application does not defend against.

If you find a vulnerability in code you intend to run, fix it in your own copy. Because the repository is archived, it cannot accept issues, pull requests or vulnerability reports.
