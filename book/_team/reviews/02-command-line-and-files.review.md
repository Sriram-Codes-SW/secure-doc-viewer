## Findings

1. **major** - Windows reader problem in Section 2.8: the chapter tells Windows readers to use Git Bash "for every command in this book", but the port-finding command `lsof -i :8080` does not exist in Git Bash, and the alternative given is PowerShell only. A Git Bash user is left with no working command and no explanation. Fix: say plainly "on Windows use PowerShell for this one task" (or give `netstat -ano | findstr :8080` which works in both), and open PowerShell instructions with how to start it. Exercise 2.5 depends on this.
2. **minor** - Formatting: in 2.5 the paragraph "Why do programs use environment variables at all? ..." runs directly into "One variable deserves special mention." with no blank line, so they render as one paragraph.
3. **minor** - Pacing: the Beginner tier is now long before the reader has typed a command (analogy, anatomy, folders, tables, figure, file commands, redirection, pipes, editors). It is reasonable, but Section 2.4 (editors) and the pipes material (`wc`, `grep`, `head`) are not needed until later; label pipes as "optional now; you will use `grep` in Chapter 6" or move to the Intermediate tier.
4. **minor** - Terms used before defined: "operating system" (2.5), "bug report" (2.1), "interface" and "address" (2.8; the definition "which network interface the program listens on" uses a second undefined word), "PID" (defined inline), "hexadecimal" (2.9), "recursive" (defined inline), "the environment" (used in the heading of Tier 2 before 2.5 defines it), "log". Add one-clause glosses; "network interface" can simply be "which network connection".
5. **minor** - Section 2.9 says "The technical-manager review (an AI review agent ...) flagged it as a high-severity finding". Good and honest. The sentence "a placeholder tends to become the real key when nobody notices" is the writer's opinion; fine, but mark as a common failure rather than fact about this project.
6. **minor** - Section 2.7 says a "fact that has a surprising consequence for passwords in Chapter 5". Chapter 5 mentions the BCrypt 72-byte limit only in passing (check the expanded Chapter 5), so make sure that consequence is really there.
7. **minor** - Windows line-ending remark: "a script with the wrong line endings fails with an error that mentions `\r`" is true and useful; confirm Chapter 6 actually shows this case (the pointer says it does).
8. **minor** - Exercise 2.2 asks to set `TILE_SIZE=512` (a name that looks like an app setting). The app does not read `TILE_SIZE`; a reader may think it changes the tile size. Use `GREETING`-style name or say "this name is only an example; the app does not read it".
9. **minor** - Analogy: phone call to a literal assistant has two breakdowns given. Good. Table captions are italic below tables and Figure 2.1 is a text tree (a figure): consistent with STYLE 13.
