## Findings

1. **major** - Exercise 25.3 (and, by the same reasoning, the "run it" exercises in Chapters 26 to 29) asks the reader to "Run `book-m0-mvp` on your own machine", but the book has not told the reader how. At this tag there is no Maven wrapper (`mvnw` arrived at `book-m5-platform`), the project targets Java 21 and Spring Boot 3.3.4, while the setup guide installs JDK 25 and says "You don't install Maven". Spring Boot 3.3.4 on JDK 25 may not start, and there is no `mvnw` to fetch Maven. Fix: add a "How to run an older milestone" box (here or in the Part IV introduction): install JDK 21 and Maven 3.9 (or copy the wrapper files from `book-m5-platform`), `git switch -c my-m0 book-m0-mvp`, run `mvn spring-boot:run`, and note that at m0 no `.env` is needed (a demo signing secret is in `application.yml`). Then reference it from every "run this tag" exercise.
2. **minor** - Mis-attribution in 25.4: "The class comment compares it with an object-storage 'bucket'". The `bucket` wording is a comment in `application.yml` (line 6: "Mirrors an object-storage "bucket" layout: ..."), not in `TileGenerationService`'s class comment (which talks about "flipbook-style readers"). Say "a comment in `application.yml`".
