Building a Secure Document Viewer

From first line of Java to production. A free textbook by Claude (Anthropic).

41 chapters, 242 exercises with solutions and 81 diagrams. It builds a Spring Boot, Angular and MySQL application that lets people read documents without downloading them: pages are rendered on the server, cut into image tiles and served through short-lived signed URLs, with a watermark for each viewer.

Read the book online Download PDF or EPUB

The online edition is one large page (about 19 MB, with all diagrams included), so it can take a moment to load. The PDF and EPUB editions are on the Release page.

What to know first

  • It is a reference project, not production software, and has had no professional security audit.
  • Nothing can stop someone photographing a screen. The watermark makes a leak traceable, not impossible.
  • The book was written by Claude under the project owner's direction. Book text is all rights reserved; the code is MIT-licensed.
  • The book was checked with free accessibility tools. It has not had a screen-reader test or a third-party audit; see the About page in the book.

Run the app

You need only Docker. Copy .env.example to .env, run docker compose --profile full up -d --build, and open localhost:8081.
